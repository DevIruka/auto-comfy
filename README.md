# Auto-Comfy / 설치

ComfyUI로 이미지와 영상을 만드는 작업을 묶어 주는 프로그램입니다. 화면은 브라우저에서 열고, 서버는 그 뒤에서 돌아갑니다.

## 필요한 것

- [Node.js LTS](https://nodejs.org/) (설치하면 `npm`도 같이 들어옵니다)
- Git, 또는 GitHub에서 ZIP으로 받기
- [Python 3.8 이상](https://www.python.org/downloads/)

## 받기

```bash
git clone https://github.com/trineedle-vtuber/auto-comfy.git
cd auto-comfy
```

## 서버

`backend` 폴더에서 한 번만 설치하고, 그다음부터는 실행만 하면 됩니다.

```bash
cd backend
npm install
npm run dev
```

서버 주소는 `http://localhost:3002` 입니다. 이 창은 켜 둔 채로 둡니다. 창을 닫으면 서버가 꺼집니다.

`.env`에는 쓰는 기능의 키만 채웁니다. ComfyUI 포드 주소는 여기 넣지 않고, 화면의 Pod Dashboard에서 등록합니다. 작업 폴더를 고정하려면 `PROJECT_DRIVE_ROOT`에 그 폴더의 전체 경로를 적습니다. 비워 두면 `backend/workspace`를 씁니다.

## 화면

다른 터미널을 열고 프로젝트 폴더에서 실행합니다.

```bash
cd frontend
npm install
npm run dev
```

브라우저에서 `http://localhost:5174` 를 엽니다. 이 창도 켜 둔 채로 둡니다.

## 얼굴 마스크

감정 파이프라인에서 얼굴을 가릴 때만 필요합니다. Python을 설치한 뒤 `facemask` 폴더에서 패키지를 설치합니다.

```bash
cd facemask
pip install -r requirements.txt
```

## 쓰기 전에

화면 상단에서 캐릭터와 스팟을 고릅니다. **경로 확인됨**이 보여야 저장 위치가 잡힙니다. 폴더가 없으면 **폴더 구조 생성**으로 아래 폴더를 만듭니다.

- `캐릭터/배너`
- `캐릭터/스팟/성인용 이미지`
- `캐릭터/스팟/성인용 영상`
- `캐릭터/스팟/감정별 이미지`
- `캐릭터/스팟/일반 영상`

ComfyUI로 그리는 작업은 **Pod Dashboard**에 포드를 먼저 등록합니다. 

## 프리셋

프리셋은 캐릭터와 장소 설정을 묶어 둔 것입니다. 화풍, 외모, 의상, 배경, 네거티브, LoRA, 해상도, 영상용 접두 프롬프트가 들어갑니다. 파일은 `backend/presets`에 저장됩니다.

상단에서 캐릭터와 스팟을 고르면 `캐릭터 스팟` 이름의 프리셋을 자동으로 불러옵니다. 그 이름의 프리셋이 없으면 아무 일도 하지 않습니다.

- **불러오기**: 고른 프리셋을 현재 화면에 넣습니다.
- **불러온 프리셋에 저장**: 방금 불러온 이름에 현재 설정을 덮어씁니다. 한 번도 불러오지 않았으면 버튼이 꺼져 있습니다.
- **현재 작업 공간의 이름으로 저장**: 상단에 고른 `캐릭터 스팟` 이름으로 저장합니다.
- **새 이름으로 저장**: 다른 이름을 직접 적습니다.

성인용 이미지, 배너, 앵커 이미지에서는 불러올 때 의상을 **Nude**로 바꿀지, **프리셋 의상 그대로** 둘지 고릅니다.

영상 자동화에 붙는 문장은 이미지 탭의 **영상용 자연어 프롬프트**에 적고 프리셋에 저장합니다. 이 칸은 접혀 있습니다.

## 이미지

**성인용 이미지 자동화**가 기본 이미지 작업입니다.

1. 작업 공간과 프리셋을 확인합니다.
2. ComfyUI 인스턴스를 고릅니다.
3. 만들 포즈를 고릅니다.
4. 생성합니다.

포즈마다 시드를 바꿔 3장 만듭니다. 결과는 `성인용 이미지/포즈이름/`에 저장됩니다. 작업 공간을 고르지 않으면 생성 버튼이 꺼집니다.

포즈 목록 위의 **포즈 프롬프트 가감**은 선택한 포즈의 프롬프트를 이번 생성에만 한꺼번에 고칩니다. 
`img-pose-config.json`은 바뀌지 않습니다. 체크를 켜면 추가 텍스트와 제거 텍스트를 적을 수 있습니다.

- 추가 텍스트는 쉼표로 나눈 태그를 맨 앞 또는 맨 뒤에 붙입니다.
- 제거 텍스트는 포즈 프롬프트 안의 같은 태그를 뺍니다. 대소문자는 구분하지 않습니다.
- 이 설정은 프리셋에 같이 저장됩니다. 체크가 꺼져 있으면 생성에 적용되지 않습니다.

**썸네일 및 배너 이미지**는 포즈와 제스처를 조합해 `캐릭터/배너`에 저장합니다. 포즈와 제스처 문장은 `banner-config.json`에서 바꿉니다.

**앵커 이미지 제작**은 포즈 목록 없이 한 장을 시험해 보는 탭입니다. Composition / Pose 칸에 구도와 동작을 직접 적습니다. 이 칸과 캔버스 비율은 프리셋에 저장됩니다. 비율은 숏폼 720×1280, 세로 1024×1536, 가로 1536×1024, 직접 입력 중 하나입니다.

시드는 한 번만 뽑고, Batch Size만큼 이미지를 만듭니다. 만든 직후에는 화면에만 보이고 폴더에는 저장되지 않습니다. 미리보기 아래 버튼을 눌러야 `감정별 이미지`에 PNG로 복사됩니다.

- `sit_neutral.png`
- `sit_neutral_nude.png`
- `stand_neutral.png`
- `stand_neutral_nude.png`

같은 라벨을 다시 누르면 그 파일을 덮어씁니다. 작업 공간을 고르지 않으면 생성 버튼이 꺼집니다. 

## 영상

성인용 영상은 새로 그리지 않습니다. `성인용 이미지` 안의 포즈 폴더를 읽고, 그 그림으로 영상을 만듭니다. 결과는 `성인용 영상`에 저장됩니다. 같은 영상의 mp4가 이미 있으면 건너뜁니다.

**성인용 영상 자동화**는 ComfyUI 포드를 씁니다.

- MiniMax 우선이 켜져 있으면, `minimax prompt.json`에 있는 포즈는 MiniMax H3로 만들고 나머지 포즈는 WAN으로 만듭니다.
- MiniMax 우선이 꺼져 있으면 MiniMax 포즈만 만들고 나머지 포즈는 건너뜁니다.
- 화면의 접두 프롬프트는 WAN으로 만드는 포즈에만 붙습니다.

한 장씩 만드는 영상은 탭이 따로 있습니다. **happyhorse 단일 영상 제작**은 `DASHSCOPE_API_KEY`, **단일 일반 영상**과 **일반 영상 자동화**는 `ARK_API_KEY`와 `SEEDANCE_MODEL_ID`가 필요합니다.
