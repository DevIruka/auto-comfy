================================================================================
  얼굴 마스킹 도구 (face_mask.py)
================================================================================

이미지에서 얼굴 영역(피부, 눈)을 자동으로 감지하고 해당 부분을 투명하게
만드는 도구입니다. 머리카락은 투명화에서 제외되어 그대로 보존됩니다.
애니메이션·일러스트 스타일 이미지에 최적화되어 있습니다.


--------------------------------------------------------------------------------
  요구 사항
--------------------------------------------------------------------------------

Python 3.8 이상

모델 파일 (최초 실행 시 자동 다운로드, 인터넷 연결 필요):
  - lbpcascade_animeface.xml  (~30KB)   : 애니 얼굴 검출용 cascade
  - sam_vit_b_01ec64.pth      (~375MB)  : SAM ViT-B 세그멘테이션 모델


--------------------------------------------------------------------------------
  설치 및 실행 순서
--------------------------------------------------------------------------------

1. Python 3.8 이상이 설치되어 있는지 확인합니다.
     python --version

2. 패키지를 설치합니다.

   [CPU 전용 — 기본]
     pip install -r requirements.txt

   [GPU(NVIDIA) 사용 시 — 더 빠름]
     먼저 본인의 CUDA 버전을 확인합니다:
       nvidia-smi
     PyTorch 공식 pip는 cu118, cu126, cu128만 제공합니다 (cu130 없음).
     CUDA 12.x/13.x 환경에서는 cu128 사용을 권장합니다:
       pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
     (CUDA 12.1이면 cu121, 11.8이면 cu118로 바꿉니다.)
     이후 나머지 패키지를 설치합니다:
       pip install opencv-python numpy segment-anything ultralytics

3. face_mask.py와 같은 폴더 안에 input, output 폴더를 만듭니다.
     mkdir input
     mkdir output

4. input 폴더에 처리할 이미지를 넣습니다.
   (PNG, JPG, JPEG, WEBP, BMP 형식 지원, 여러 장 가능)

5. 스크립트를 실행합니다.
     python face_mask.py

   * 최초 실행 시 모델 파일(~375MB)이 자동으로 다운로드됩니다.
     인터넷 연결이 필요하며 수 분이 걸릴 수 있습니다.
   * CPU로 실행하면 이미지 한 장당 1~2분 정도 소요됩니다.
   * 처리 결과는 output 폴더에 PNG 형식으로 저장됩니다.


--------------------------------------------------------------------------------
  사용법
--------------------------------------------------------------------------------

기본 실행:
  python face_mask.py

소프트 마스크 옵션 (경계를 부드럽게):
  python face_mask.py --soft

폴더 구조:
  face_mask.py
  input/         ← 처리할 이미지를 여기에 넣으세요
    image1.png
    image2.jpg
    ...
  output/        ← 처리 결과가 여기에 저장됩니다 (자동 생성)
    image1.png
    image2.png
    ...

출력 형식: RGBA PNG (투명 영역 = alpha 0)


--------------------------------------------------------------------------------
  동작 원리 — 단계별 설명
--------------------------------------------------------------------------------

[1단계] 얼굴 바운딩 박스 검출
  - lbpcascade_animeface 분류기를 사용하여 이미지에서 얼굴 영역의
    위치(x, y)와 크기(w, h)를 찾습니다.
  - 실사 얼굴용 Haar cascade 대신 이 분류기를 사용하는 이유는
    애니메이션·일러스트 스타일 얼굴에 특화되어 있기 때문입니다.

[2단계] SAM 이미지 임베딩 (1회 실행)
  - SAM(Segment Anything Model, ViT-B) 모델이 이미지 전체를
    한 번만 인코딩하여 내부 표현(임베딩)을 생성합니다.
  - 이후 여러 번의 세그멘테이션 예측을 수행해도 이 단계는
    재실행되지 않아 처리 시간이 절약됩니다.

[3단계] 눈 위치 추정
  - 얼굴 ROI 안에서 눈 좌표를 구합니다.
  - 방법은 상황에 따라 달라집니다:

    (a) 두 눈 모두 cascade로 검출된 경우
        → cascade 결과를 그대로 사용합니다.

    (b) 한쪽 눈만 검출된 경우 (예: 머리카락에 가려진 눈)
        → 기하학적 원근 추정:
          검출된 눈의 얼굴 가장자리까지의 거리에 원근 압축 계수(0.35)를
          곱하여 반대쪽 눈의 위치를 추정합니다.
          (3/4뷰 얼굴에서 원거리 눈은 가장자리에 더 가깝게 압축되어 보임)
        → 로컬 분산 최대점으로 보조:
          눈은 어두운 iris와 밝은 sclera(흰자)가 인접하므로
          주변보다 국소 대비(분산)가 높습니다. 이 성질을 이용해
          머리카락에 가려진 눈도 근사 위치를 추정합니다.

    (c) 두 눈 모두 미검출
        → 얼굴 bbox 비율 기반 fallback 좌표를 사용합니다.

[4단계] 피부 SAM
  - SAM에 포인트 힌트와 박스를 제공하여 얼굴 피부 윤곽을 감지합니다.
  - Box  : 얼굴 bbox 상단 18%를 제거하여 머리카락 영역 배제
  - Positive (포함할 곳): 코, 볼(좌·우), 턱, 코 위, 눈 위치
  - Negative (제외할 곳): bbox 상단 중앙 (머리카락 억제)
  - SAM이 반환하는 3개의 후보 마스크 중 면적 비율(10~85%)과
    신뢰도 점수가 가장 높은 마스크를 선택합니다.

[5단계] 눈 SAM (각 눈마다 개별 실행)
  - 피부 SAM만으로는 눈 안쪽(iris, pupil) 영역까지 커버하지 못하므로
    각 눈에 대해 별도로 SAM을 실행합니다.
  - Box  : 눈 중심 좌표를 기준으로 얼굴 너비의 30%, 높이의 28%를
           반경으로 설정 (머리카락에 가려진 눈도 커버하도록 여유 있게)
  - Positive: 눈 중심 좌표 1개

[6단계] 마스크 합산 및 후처리
  피부 마스크와 모든 눈 마스크를 합칩니다. 이후 세 가지 정제 작업을
  순서대로 수행합니다:

  (a) Morphological Close (9×9 타원 커널, 3회 반복)
      → 머리카락 틈새나 눈썹 주변의 작은 구멍을 메웁니다.

  (b) Flood Fill (이미지 모서리에서 시작)
      → 마스크가 형성한 경계 ring 안쪽의 빈 영역을 모두 채웁니다.
        이 단계에서 얼굴 내부의 코, 입, 눈 사이 등 SAM이 직접
        잡지 못한 영역도 자동으로 채워집니다.

  (c) Connected Component 필터
      → bbox 면적의 0.5% 미만인 아주 작은 잡음 섬은 제거합니다.

[7단계] 헤어 SAM 및 차감
  - 얼굴 위에 걸쳐 있는 머리카락이 투명해지지 않도록 보정합니다.
  - SAM으로 머리카락 영역을 감지합니다:
    - Box  : 얼굴 bbox보다 위·좌우로 확장 (머리카락은 얼굴 밖으로도 뻗음)
    - Positive: 얼굴 바로 위(뱅), bbox 상단 내부, 좌·우 측면 머리카락
    - Negative: 코 아래, 볼, 턱 (피부 영역)
  - 최종 마스크 = 얼굴 마스크 AND NOT 헤어 마스크
    → 머리카락이 얼굴 위에 겹쳐 있는 부분은 투명화에서 제외되어
      머리카락이 그대로 보이게 됩니다.

[최종 출력]
  - 완성된 마스크 영역의 알파 채널을 0으로 설정합니다.
  - RGBA PNG 형식으로 저장합니다.
    · 얼굴 피부·눈 영역 → 투명 (alpha = 0)
    · 머리카락·배경 등  → 불투명 유지 (alpha = 255)


--------------------------------------------------------------------------------
  처리 흐름 요약 (다이어그램)
--------------------------------------------------------------------------------

  입력 이미지
      │
      ▼
  [1] 얼굴 bbox 검출 (lbpcascade_animeface)
      │
      ▼
  [2] SAM 이미지 임베딩 (1회, 가장 무거운 연산)
      │
      ├─▶ [3] 눈 위치 추정 (cascade → 기하학적 추정 → variance 보조)
      │
      ├─▶ [4] 피부 SAM      (볼·코·턱 positive / 상단 negative)
      │
      ├─▶ [5] 눈 SAM × N   (각 눈 개별 실행)
      │
      ├─▶ [6] 합산 + Morph Close + Flood Fill + 컴포넌트 필터
      │
      └─▶ [7] 헤어 SAM → 얼굴 마스크에서 차감
      │
      ▼
  출력 RGBA PNG


--------------------------------------------------------------------------------
  참고 사항
--------------------------------------------------------------------------------

- GPU(CUDA)가 있으면 자동으로 사용합니다. 없으면 CPU로 실행됩니다.
  CPU 실행 시 처리 시간이 다소 걸릴 수 있습니다.

- 여러 얼굴이 있는 이미지도 지원합니다. 감지된 얼굴 수만큼 반복 처리됩니다.

- 원근감이 강한 3/4뷰 얼굴에서 머리카락에 가려진 눈도 기하학적 추정으로
  처리됩니다. 단, 눈이 머리카락에 완전히 가려진 경우 해당 픽셀은
  머리카락으로 인식되어 투명화에서 제외될 수 있습니다.
